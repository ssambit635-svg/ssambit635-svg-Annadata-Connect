# Screenshots — status

⚠️ Most PNGs in this folder predate the unified **Annadata Connect** brand
(they show the old "Saathi" name/art and a pre-redesign landing page).
`saathi/00-app-icon.png` has been replaced with the real app icon.

To recapture everything from the current UI:

```bash
npm run dev:backend            # terminal 1
npm run dev:frontend           # terminal 2
npm --prefix frontend run screenshots
```

Then review each image, and delete shots of screens that no longer exist
before using them in the README/PPT. Authenticated farmer/officer screens:
sign in with a demo account in `/?app=1` (or the installed APK) and capture
at 390×844; keep the same file names so README links keep working.
